# Asmongone

Copyright (c) 2026 @fukkenawesome

Asmongone was created as a simple, optional tool for people looking to improve their digital well-being by taking greater control over the content they encounter online. Because sometimes, improving your internet experience is less about what you add and more about what you remove.

tl&dr: Chrome extension that filters selected Asmongold-related content from supported sites. Currently supportet sites include: youtube, x/twitter, reddit, twitch.
